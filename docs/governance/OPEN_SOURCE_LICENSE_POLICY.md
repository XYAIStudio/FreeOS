# openXYOS 开源许可证策略

## 出站许可证

openXYOS Core 以 Apache-2.0 发布。官方商标、Logo、域名、兼容认证和企业服务不随代码许可证授权，适用 `TRADEMARKS.md`。

## 入站依赖分级

| 等级 | 处理规则 |
| --- | --- |
| 允许 | Apache-2.0、MIT、BSD-2-Clause、BSD-3-Clause、ISC、CC0；保留版权和 NOTICE。 |
| 法务审查 | MPL-2.0、EPL-2.0、LGPL、CDDL、SSPL、非标准商业条款、字体/模型/数据许可证。 |
| 禁止进入 Core | 未知许可证、仅限非商业、禁止竞争、禁止修改、来源不明、与 Apache-2.0 冲突的代码或素材。 |

GPL/AGPL 及其组合关系必须由律师和维护者对具体使用方式共同审查；在批准前不得合入 Core 或商业发行链路。

## 提交要求

- 新依赖须在 PR 中说明名称、版本、许可证、用途与替代方案。
- 复制的代码、模板、图片、字体、模型或数据必须有可追溯来源和许可证。
- 不得删除第三方版权、专利或 NOTICE 声明。
- 发布前生成 SBOM 并将完整报告保存至私有发布档案。

## 例外

任何例外均需权利人书面批准并记录在私有发布档案；公开仓库中仅记录经批准可公开的结论，不放入合同、报价、客户信息或未公开技术资料。
