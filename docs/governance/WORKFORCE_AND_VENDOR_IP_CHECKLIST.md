# 员工、外包与合作开发权属核对表

> 首发前逐人、逐合同核对；完成后的记录仅保存于私有档案。

## 员工

- [ ] 劳动/聘用协议明确职务开发代码、文档、设计、测试、提示词和数据处理成果的归属。
- [ ] 协议包含保密、发明披露、专利申请协助、离职交接与密钥回收要求。
- [ ] 贡献开源代码前已获得公司授权，且使用的是公司批准的账号与仓库。
- [ ] 未导入前雇主、客户或未授权第三方代码、资料、数据和模型输出。

## 外包与合作方

- [ ] 合同明确交付物著作权及可修改、再许可、商业发行权归雄元科技，或具有足以实现同等控制的排他许可。
- [ ] 合作方保证其员工、分包商和素材提供方已完成相应权属授权。
- [ ] 交付包含源码、构建说明、测试、SBOM、第三方许可证与作者清单。
- [ ] 已完成代码、密钥、数据、恶意代码和许可证审查，并留存验收记录。
- [ ] 合同包含侵权、泄密、开源许可证违规的替换、协助和赔偿责任。

## 合作研发与专利

- [ ] 合作协议约定软件著作权登记主体、专利申请主体、发明人署名和费用承担。
- [ ] 对共同成果约定公开、许可、转让、维权和商业化的书面决策机制。
- [ ] 未经专利负责人确认，不公开未披露的技术方案和权利要求关键实现。
