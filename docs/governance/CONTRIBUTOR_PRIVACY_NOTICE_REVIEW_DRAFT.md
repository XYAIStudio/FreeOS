# 贡献者隐私声明审核稿

> **非生效文本。** 在补充实际运营主体、联系邮箱、保存期限、跨境处理情况并经律师审核后发布。

为处理 Issue、讨论、PR、CLA/CCLA 和安全报告，项目方可能处理贡献者主动提供的姓名、GitHub 账号、邮箱、雇主信息、提交记录、协议签署记录和沟通记录。

处理目的限于：验证贡献来源和授权、维护开源项目、处理安全与合规事项、保留版本历史及履行法定义务。公开仓库中的提交、讨论和提交者标识可能长期公开；协议和内部审核材料应保存于受控私有系统，仅向有职责的维护者、法务和服务提供商开放。

贡献者应避免在公开渠道提交身份证件、客户数据、密钥、未公开专利材料、商业秘密或其他非必要个人信息。正式声明应提供联系渠道、访问/更正/删除请求路径、投诉路径和适用的隐私法信息。
