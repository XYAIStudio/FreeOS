<p dir="rtl">
يجمع FreeOS بين Octop وopenXYOS في منصة واحدة تستضيفها بنفسك. النماذج وقواعد المعرفة تبقى محلية قدر الإمكان. تتعزّز الأصول فيما بينها. يشمل الهدف تصدير شفرة مصدر openXYOS جديدة. الاتجاه: نقل openXYOS <strong>إلى</strong> المضيف، لا تضمين Node إلى الأبد. العقد: <a href="docs/product-contract.md">product-contract.md</a>.
</p>

<h2 dir="rtl">القدرات</h2>

<ul dir="rtl">
<li>إنشاء وتنسيق الخبراء ومساعدي الذكاء الاصطناعي وسير العمل وقواعد المعرفة وقدرات التنظيم.</li>
<li>تخصيص الأدوار والواجهات والأتمتة في مساحة العمل المحلية لـ openXYOS.</li>
<li>تفعيل الوكلاء والدردشة الجماعية ومعالجة المعرفة والتوليد بعد إعداد نموذجك.</li>
<li>استخدام قوالب FreeOS والحوكمة وضوابط الجودة والتجميع، ثم تصدير شفرة لنظام مستقل.</li>
</ul>

<h2 dir="rtl">بداية سريعة</h2>

<p dir="rtl">يمكن لمستخدمي Windows تنزيل المثبّت المناسب من <a href="https://github.com/XYAIStudio/FreeOS/releases/latest">Releases</a>. للتشغيل من الشفرة المصدرية:</p>

```bash
git clone https://github.com/XYAIStudio/FreeOS.git
cd FreeOS
uv sync
uv run freeos run
```

<p dir="rtl">
FreeOS أشبه باستوديو خاص بك: تستقرّ أولًا على جهازك، مع التسجيل وتسجيل الدخول والبيانات والجلسات في متناول يدك. يمكن أن تُفتح خدمات أو تراخيص أوسع لاحقًا كخيارات، دون أن تسدّ البداية. قدرات التنظيم كغرفة أخرى في ذلك الاستوديو ترتّبها على هواك — نفس FreeOS الذي يضم الدردشة اليومية والمساعدين، من دون دمج طريقتَي الدخول في طريقة واحدة. لا تنشر مفاتيح API أو الرموز المميّزة أو بيانات العملاء الحقيقية.
</p>
