## 最低证据要求

- 商标：证书、申请回执、权利人、类别、有效期、许可或转让文件。
- 软著：申请表、鉴别材料版本、提交回执、证书、对应 Git 标签与 SHA-256。
- 专利：申请号、申请日、申请人、发明人、权利要求摘要、公开状态、代码模块映射。
- 员工/外包：合同、保密与权属条款、交付验收、人员名单、第三方组件清单。

只有权利主体、状态与证据位置均可确认的资产，才能被标记为“可公开宣传”。
