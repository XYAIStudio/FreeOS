# 人机源码公开边界

人机技术方法相关已申报发明专利的权利人为北京雄元科技有限公司。本文件只说明公开仓库的发布边界，不包含相关技术方案、流程、数据结构、测试样例、图示、对比材料或申请内容。

## 公开版规则

`openXYOS` 只发布独立设计的通用组织管理能力，例如多租户、身份与权限、聊天、任务、知识、审计事件、插件接口和可配置工作流。

人机技术及其可复现旁证不属于公开版，包括但不限于专有实现、接口、数据模型、自动决策规则、演示、测试、种子数据、历史研发资料和构建产物。改名、删除注释或局部删改不改变该规则。

公共版中的“治理引擎”是通用功能名称，不表示包含或实现任何未公开的人机技术方法。

## 发布核验

每次公开发布前，维护者应：

1. 执行 `npm run verify:open-source`；该检查会拦截保密方法标识、密钥样式和运行时数据。
2. 核验代码、测试、前端文案、示例数据、历史文档及构建产物均不包含专有技术材料。
3. 在私有台账中保存文件处置与复核证据；台账、技术交底书、对比报告、申请材料及客户资料不得提交公共仓库。
4. 由北京雄元科技有限公司指定负责人确认首发范围；重大边界调整应进行外部知识产权复核。

本文件不构成专利有效性、侵权、自由实施或许可意见。
