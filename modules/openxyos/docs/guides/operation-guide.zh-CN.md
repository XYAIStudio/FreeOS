# openXYOS 中文操作指南

本指南对应社区候选版的本地运行界面。功能可因租户模块配置和用户权限而不同；屏幕上的提示、权限限制和实际按钮优先于本文。

## 1. 首页与本地启动

访问 `http://localhost:5174` 可看到项目介绍、核心能力、智能体定制演示、模块清单和源码入口。

1. 选择“在线体验”。
2. 若要测试模型能力，选择模型服务、填写自己的 API Key，再选择“保存并进入智能体验”。密钥不会在页面回显；不使用密钥时，选择“暂不配置，只体验基础功能”。
3. 选择管理员或普通员工测试视角，或转至“使用其他账号登录”。

没有可用后端时，先在项目根目录执行 `npm run dev`。首次使用模型前，请确认模型供应商、网络与密钥权限；不要将密钥粘贴到 Issue、截图或源码中。

## 2. 登录、退出与权限

在 `/auth` 页面输入邮箱和密码，勾选协议后选择“登录”。本地演示数据仅在明确启用种子数据后才可用。登录后，侧边栏只显示当前租户已启用且当前用户有权访问的模块。使用右上角或侧边栏的“退出登录”清除本地会话。

管理员可管理模块、模型和用户；普通用户不会因模块显示而获得管理权限。登录后若出现“模块配置加载失败”，选择“重新加载”；仍失败时检查 API 健康接口、`JWT_SECRET` 是否在服务重启后变更，以及浏览器是否保留了旧会话。

## 3. 工作台

路径：`/app`。工作台展示组织成员、任务、会话和知识统计，以及已启用模块的快捷入口。点击模块卡片或左侧导航进入具体功能。它是基础入口，不能在模块管理中关闭。

## 4. 通知公告

路径：`/announcements`。浏览公告列表，打开公告查看内容和已读状态。拥有发布权限的用户可新建、编辑或发布公告；发布前确认受众、正文和附件不包含个人信息、客户资料或密钥。该模块适合作为二次开发示例。

## 5. 组织架构

路径：`/org`。查看集团、公司、部门、岗位和汇报关系。管理员按页面操作新增或调整组织节点、部门及岗位；变更前先确认所属租户和上级关系。普通用户仅能看到其授权范围内的组织信息。

## 6. 人机资源

路径：`/employees`。浏览人类员工、AI 员工、备选员工和人才市场。管理员可查看人员详情、招募人才市场中的智能体、补充岗位职责并安排部门。人员资料应使用演示或已获授权的数据。

## 7. 技能插件

路径：`/skills`。查看技能目录、插件信息和能力装配状态。启用或新增插件前，先审查来源、许可证、所需密钥、网络权限及数据流向；插件的安装不等于已获生产授权。

## 8. 沟通协作

路径：`/chat`。创建或选择单聊、群聊，发送文本并查看人类与智能体的独立回复建议。需要模型能力时先在系统设置配置自己的模型密钥。涉及外发、删除、支付或生产修改的内容应在系统外完成必要的人工确认。

## 9. 智能体定制

路径：`/agents`。填写名称、定位、能力和行业经验，上传支持格式的参考资料，并按需关联知识库地址。提交前确认资料有权使用且不含密钥、客户机密或未公开技术材料。生成的顾问型智能体进入人才市场；管理员招募后将其转入备选员工，并补充部门和岗位信息。

## 10. 任务管理

路径：`/tasks`。创建任务，填写标题、描述、负责人、截止时间或子任务；在执行过程中更新状态并提交验收。任务和状态流转是可二次开发示例，团队可按自身流程扩展字段、规则和通知。

## 11. 知识库

路径：`/knowledge`。上传受支持的资料，等待安全检查和文本解析后进行浏览、检索或关联。先确认文件版权、隐私和客户授权；上传失败时查看文件类型、大小、扫描结果与后端日志。不要上传生产数据库、凭据、私钥或保密专利材料。

## 12. 反思引擎

路径：`/reflections`。选择协作或任务记录，整理复盘结论、改进项和可复用经验。输出是组织学习素材，应由负责人审核后再作为规范或知识沉淀使用。

## 13. 治理引擎

路径：`/governance`，通常仅管理员可用。查看通用权限、沟通规则、流程模板和审计事件，并按页面权限调整配置。这里的“治理”是公开版通用功能，不代表任何未公开的方法或自动决策机制。

## 14. 系统设置

路径：`/settings`，管理员可用。

- **公司设置**：维护当前租户的基础信息。
- **模块管理**：开关可配置模块、编辑显示名称；工作台和系统设置不可关闭。
- **AI 大模型**：选择服务商、填写并保存当前租户自己的 API Key；保存后检查掩码显示和实际连通性。
- **用户管理**：按授权范围管理用户和角色。

保存设置会影响当前租户的运行体验。进行模块关闭、模型切换或用户权限调整前，应在非生产数据上验证并保留变更记录。

## 常见问题

- **无法登录**：确认 API 在 `http://localhost:3000/api` 可访问，确认演示数据已按说明初始化，或使用有效的自建账号。
- **页面空白或旧样式**：强制刷新浏览器，并确认 `npm run dev` 的前端进程仍在运行。
- **智能能力不可用**：确认已配置有效 API Key、服务商地址可达且模型服务有权限；没有模型密钥时基础组织功能仍可使用。
- **准备贡献代码**：阅读 [贡献指南](../../CONTRIBUTING.md)、[安全政策](../../SECURITY.md) 和 [模块二次开发说明](../module-development.md)。
