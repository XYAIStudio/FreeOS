# Wordmark font

The OpenXYOS Brand Bold subset uses the unchanged `openXYOS` glyph designs
from Adobe Source Han Sans SC Bold (思源黑体).

Source: https://github.com/adobe-fonts/source-han-sans/tree/release/OTF/SimplifiedChinese

License: SIL OFL 1.1, included in SourceHanSans-LICENSE.txt.
The subset's internal font names are changed to respect the reserved name.
Regenerate using scripts/build-wordmark-font.py with the upstream OTF at
artifacts/SourceHanSansSC-Bold.otf (fontTools required).
